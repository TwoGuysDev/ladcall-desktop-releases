# LadCall para Windows

Instaladores e atualizações do app desktop do [LadCall](https://ladcall.io).

**Baixar:** [LadCall-Setup.exe](https://github.com/TwoGuysDev/ladcall-desktop-releases/releases/latest/download/LadCall-Setup.exe)
(Windows 10 ou 11, 64 bits). O instalador não pede administrador e o app se atualiza sozinho.

Este repositório só guarda os arquivos das versões (`.exe`, `.blockmap`, `latest.yml`, `beta.yml`), que o app
instalado consulta para se atualizar. Versões marcadas como *pre-release* são do canal Beta.
